# 프로젝트 프로필

이 파일은 프로젝트 고유 사실의 슬롯이다. 설치·재설치 시 덮어쓰지 않는다.
README와 실제 코드로 확인한 사실만 채우고, 미확인은 그대로 표시한다.

## 1. 목표와 제출물

- 목표: 미확인 — 과제 README에서 확인
- 필수 조건과 제출 경로: 미확인 — 과제 안내가 우선
- 요구별 출처·성공 조건·판단·검증 근거: `.harness/task-evidence.md`
  (과제에 정본 문서가 있으면 그 경로를 연결)
- 사용자에게 설명할 언어: 한국어

## 2. 스택과 디렉토리

- 런타임·패키지 매니저: 미확인
- 소스·테스트·실행 진입점: 미확인

## 3. 검증

기계 검증 명령의 정본은 `.harness/checks.json`이다. 이곳에 명령을 중복 기입하지 않는다.
검증할 수 없는 항목은 이유와 대체 확인 방법을 기록한다.

- 수동 관찰 대상: 미확인
- 실행·미리보기 포트와 경로: 미확인

## 4. 불변식과 경계

- 어기면 오류가 되는 프로젝트 규칙: 미확인
- 입력·출력·저장 구조가 만나는 경계와 공유 계약: 미확인

## 5. 실행과 제출

- 서버 실행·결과 확인 방법: 미확인
- 시험 모드에서는 제공 환경에서만 작업하고 외부 push·게시·전송을 하지 않는다.
- 제출 전 필수 파일 경로와 저장 상태를 확인한다. 화면 제출은 응시자가 직접 한다.

## 6. 선행 결정과 진행 상태

- 지식 진입점: 없음 — 필요한 경우 작업 공간 안의 문서 경로를 지정
- 현재 작업 상태: `.harness/work/progress.md`
- 결정·대안·선택 이유·검증·남은 한계를 작업 중 기록한다.
