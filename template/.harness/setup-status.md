# 하네스 적용 진행

제공 Codex가 실제 관찰로 갱신하는 기록이다. 재설치 시 보존한다.
파일 설치만으로 아래 항목을 완료 처리하지 않는다. 상태를 적었다는 사실 자체도 실행 증거는 아니다.
상태: 대기 / 진행 / 확인 / 실패 / 환경 제한 / 사용자 조치 필요 / 미확인.

| 항목 | 상태 | 실제 근거·남은 작업 |
| --- | --- | --- |
| 실제 과제 루트·반입 경로 | 대기 | `.harness/state/setup-context.json` 확인 |
| 프로필·요구·지식 경로 | 대기 | 실제 과제 근거로 채우기 |
| 검증 명령 등록·실행 | 대기 | 명령·종료 코드·최신 영수증 |
| Skill | 대기 | 파일 직접 읽기 / 자동 발견을 구분 |
| 모델·effort | 미확인 | 런타임 관찰, 설정 파일은 실행 증거가 아님 |
| 네이티브 역할 | 미확인 | 파일 존재 / 런타임 발견 / 실제 호출을 구분 |
| 훅 | 미확인 | 등록 / 신뢰 / 실제 콜백을 각각 기록 |
| Sol 리뷰 A | 대기 | 실행 ID·모델·대상 지문·응답 경로 |
| Sol 리뷰 B | 대기 | 실행 ID·모델·대상 지문·응답 경로 |
| 리뷰 병합·최종 검증 | 대기 | 지적 처리·최신 검증 결과 |

## 이어갈 작업

- 다음 단계: `.harness/setup.md`를 읽고 현재 세션에서 가능한 설정부터 수행.
- 사용자에게 필요한 최소 조치: 아직 미확인.
- 실제 과제 구현·제출 완료 여부: 이 설치 기록으로 판정하지 않는다.
