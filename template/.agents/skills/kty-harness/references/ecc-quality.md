# ECC 기준의 Codex 적용

ECC는 Codex용 `.codex/` 설정과 `.agents/skills/`를 제공한다.
이 하네스는 공개 ECC 규칙의 고정 버전을 함께 배포하므로 실행 중 플러그인 설치가 필요 없다.
원문·라이선스·커밋은 `vendor/ecc/`와 저장소 `PROVENANCE.md`에 기록돼 있다.

- 코드 작성·검수: [코딩 기준](vendor/ecc/coding-style.md)을 읽는다.
  입력 경계 검증, 명시적 오류 처리, 응집된 모듈, KISS·DRY·YAGNI를 적용한다.
  불변성은 언어 관용구·성능·의도적 상태 변경 계약에 맞춰 판단한다.
- 테스트: [테스트 기준](vendor/ecc/testing.md)을 참고해 중요한 동작을 실패부터 검증한다.
  이 시험용 하네스는 모든 변경에 80% 커버리지·모든 테스트 종류를 일괄 강제하지 않는다.
  실제 변경의 위험과 과제 필수 조건에 맞는 검증을 선택한다.
  원문의 특정 에이전트 이름은 `roles.md`의 대응 역할로 수행한다.
- 보안 경계를 바꿀 때: [보안 기준](vendor/ecc/security.md)의 관련 항목을 확인한다.
  SQL·XSS·CSRF·인증·요청 제한은 해당 경계가 있을 때 적용한다.

ECC 원문은 참고 기준이다. 프로필·원칙·현재 요청과 제공 환경 규칙을 먼저 따른다.
ECC 전체 설정의 MCP 서버·다른 모델·알림·브라우저 자동화는 이 패키지에서 활성화하지 않는다.
