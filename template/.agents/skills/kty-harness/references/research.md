# 레퍼런스 수집과 독립 평가

## 메인의 판단과 범위

공개 선례가 결정을 바꿀 때 또는 사용자가 조사를 요청했을 때 수행한다.
같은 문제를 다른 제약에서 푼 인접 분야도 포함하고, 정확히 같은 도메인이 아니라는 이유만으로 제외하지 않는다.
먼저 실제 요구를 내부에서 정리한 뒤 **일반적인 공개 기술 개념**으로 검색한다.
시험 문제 원문·고유 데이터·코드·로그를 외부 검색어·MCP 인자에 넣지 않는다. 제공 환경의 허용 도구만 쓴다.
관련 반도체 카드·색인은 시작점이며 실제 과제 조건이나 원문 검증을 대신하지 않는다.

## kty_research_collector — 수집 [rc]

- 질문을 3–5개 이하의 필요한 하위 질문으로 나누고 검색 범위·포함/제외 기준·질의를 정한다.
- 공식 문서·원 논문·공개 저장소를 우선한다. 제공 검색/읽기 도구를 사용하고 별도 키·플러그인 설치를 전제하지 않는다.
- 문헌: 저자·연도·학술지/프리프린트 구분·DOI/URL. 웹: 기관/저자·날짜·URL·문서 유형.
  오픈소스: 저장소·라이선스·최근 변경일·관찰한 스타 수·의존성. 확인 못 한 값은 미확인이다.
- 각 RC-ID에 주장·적용 조건·짧은 근거 인용 또는 정확한 요지·원문 절/페이지·검색 경로를 기록한다.
- 찾지 못한 영역·실패한 도구·상충 자료를 숨기지 않는다. 인기와 요구 적합도를 혼동하지 않는다.
- 채택 결론은 내리지 않는다. 수집 결과를 반환하고 evaluator가 독립 평가한다.

## kty_research_evaluator — 독립 평가 [re]

수집자와 새 컨텍스트에서 실행한다. 받은 요약을 사실로 취급하지 않고 원문을 직접 열어 대조한다.
출처 실존·메타데이터·인용 위치·주장 범위·적용 조건·최신성·반박·이해충돌·독립 교차 근거를 확인한다.
확인된 허위 인용·잘못 연결된 근거는 기각한다. 접속 실패·유료 전문 미확인은 허위와 구분해 보류한다.
상충 근거는 삭제하지 않는다. 공식 제품 사양과 벤더의 우월성 주장을 구분하며 출처 유형만으로 결론을 대신하지 않는다.

원본의 항목별 평가 축을 유지한다. 점수는 근거와 함께 기재하고 미확인 축을 임의 점수로 채우지 않는다.
- 논문/문헌: 출처 신뢰 30 / 방법론·주장 일치 30 / 재현성 20 / 최신성·적용성 20.
- 오픈소스: 유지보수 30 / 요구 적합도 30 / 라이선스·생태계 20 / 문서 품질 20.
- 공식 사양·웹 문서: 발행 주체·버전·원문 일치·적용 범위를 설명한다. 맞지 않는 논문 점수를 억지 적용하지 않는다.

각 RC-ID에 `채택 | 보류 | 기각`과 실제 연 URL/범위·이유를 반환한다. 점수가 높아도 핵심 근거가 없으면 채택하지 않는다.
평가자는 부족한 출처를 직접 보충하지 않고 재수집 대상을 메인에게 돌려준다.

## 전달과 실패

메인이 채택분·반대 근거·공백·신뢰 수준을 종합하고 설계·계획의 어느 결정에 적용했는지 연결한다.
채택 0건도 유효한 결과다. 재수집은 1회까지, 총 2사이클 후에도 부족하면 제약과 필요한 결정을 보고한다.
독립 도구 미지원이면 메인이 수집과 원문 대조를 순서대로 수행하고 **독립 평가 미실행**을 명시한다.
원문을 열 수 없으면 해당 범위를 미확인으로 두고 평가 완료를 주장하지 않는다.
전체 읽기 전용에서는 수집/평가 결과를 대화로 반환한다. 외부 저장·개인 vault 반영은 하지 않는다.
