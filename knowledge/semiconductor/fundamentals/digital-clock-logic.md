# 디지털 논리·클록·주파수

ID: `F08` · 단계 1 · 출처 확인: 2026-10-30

디지털 회로는 물리적 신호를 논리 상태로 해석하며 클록의 주기와 주파수는 반복 속도를 표현한다.

## 원리

NOT은 반전, AND는 둘 다 1일 때 1, OR는 하나 이상 1일 때 1, XOR는 두 입력이 다를 때 1이다. 실제 신호 전환은 순간적이지 않으며 논리 상태의 판정 기준은 소자 규격에 달려 있다.

## 공식·단위와 적용 조건

f = 1/T, Hz = 주기/초. 듀티 비율 = high 시간/T. 1 GHz = 10⁹ Hz. 클록 수와 데이터 전송 횟수는 인터페이스 계약으로 연결해야 한다.

## 직접 만든 예제

500 MHz의 주기는 2 ns다. 주기마다 high가 0.5 ns이면 듀티 비율은 25%다. (A,B)=(1,1)일 때 AND=1, OR=1, XOR=0이다.

## 혼동·적용 한계

GHz를 GB/s로 바로 바꾸지 않는다. 논리 1을 모든 칩에서 5 V라고 가정하지 않는다. 보관된 강의의 오래된 특정 구현 수치는 쓰지 않는다.
