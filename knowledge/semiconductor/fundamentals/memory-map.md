# 메모리·로직·휘발성 구분

ID: `F10` · 단계 1 · 출처 확인: 2026-10-30

메모리는 데이터 저장을, 로직은 연산·제어를 담당하며 메모리는 전원 차단 후 데이터 유지 여부로 구분할 수 있다.

## 원리

DRAM과 SRAM은 휘발성 메모리 계열이다. NAND Flash는 비휘발성 메모리다. RAM이라는 이름의 random access와 비휘발성 여부는 서로 다른 분류 축이다. 이 단계는 제품 지도를 제공하며 셀 동작·리프레시·소거 단위의 상세는 3단계 범위다.

## 공식·단위와 적용 조건

용량은 B 또는 bit, 지연은 s, 대역폭은 B/s 또는 bit/s로 따로 기록한다. 저장 분류만으로 특정 제품의 속도·수명·소비전력을 계산하지 않는다.

## 직접 만든 예제

문제에서 재시작 후 설정 보존을 요구하면 휘발성 작업 메모리만으로 충족할 수 있는지 확인하고, 영속 저장·복구 조건을 별도로 확인한다.

## 혼동·적용 한계

비휘발성은 무한 수명·무오류·영구 보존의 보증이 아니다. 공개 소개의 “permanent” 표현을 제품 보존 기간으로 사용하지 않는다. ROM 계열과 쓰기 가능한 Flash의 동작을 동일시하지 않는다.
