# 반도체 지식 패키지 검증 기록

확인일: 2026-10-30. 공개 기초 지식 패키지 검증이며 실제 Probe 접속·제공 Codex 실행 검증은 아니다.

## 1단계 검증 범위

- Markdown 본문 11개, UTF-8 JSONL 색인 11개, 출처 레지스트리 14개.
- ID 유일성, 본문 경로 실존, source ID와 본문 URL 일치, 선수/관련 ID 실존, 선수 관계 비순환.
- Markdown 내부 파일 링크 확인.
- 검색 예시 8개에서 해당 개념 포함: 정전용량→F03, donor→F06, GiB→F07,
  MHz→F08, wafer→F09, NAND→F10, latency→F11, 에너지→F04.
- 본문의 직접 만든 계산 12건을 수치 계산으로 대조:
  3 mA, 0.5 mA, 20 fC, 6 J, 8 J, 10²² m⁻³, 2 GB,
  약1.863 GiB, 1 GB/s, 2 ns, 25%, 0.05 s. XOR 네 입력 조합 확인.
- 출처 14개는 공개 원 작성 기관의 페이지를 읽고 사용 범위를 기록했다.
  제품 현황으로 오해할 오래된 수치는 제외했다. 단위·공식 조건·가상 예제와 제품 수치 구분을 작성자가 검토했다.

구조·산술 검증은 기술 내용 전체의 정확성을 자동 증명하지 않는다.
독립 전문가 검수·실제 출제 적합성 평가·Sol+Sol 모델 검수는 이 지식 패키지에 아직 수행하지 않았다.
사용된 확인 코드는 작성 작업의 임시 점검이며 반입 시 실행할 필요가 없다.

## 재확인 방법

반입 저장소에서 `index.jsonl`의 관심 ID를 읽고 `path`로 본문을 연다.
`sources.json`의 출처 ID·확인 날짜와 본문 링크를 대조한다.
예제는 단위를 SI 기본값으로 맞춰 직접 계산하고, 실제 과제 수치로 바꿀 때는 조건을 먼저 확인한다.

3–4단계는 미작성이다. 실제 과제에서의 지식 선택·적용·실행 결과는 별도로 검증해야 한다.

## 2단계 추가 검증 — 2026-10-30

- 소자·공정 본문 14개(P01–P14)를 추가해 총 25개 개념, 출처 총 35개.
- 전체 색인/출처 JSON 파싱, ID·출처 URL 유일성, 본문 존재, 본문/색인 제목과 ID 일치,
  출처 ID/본문 URL 일치, 선수/관련 ID 실존, 선수 관계 비순환, 내부 파일 링크를 확인했다.
- 모든 본문에 적용 한계·확인 질문·출처가 있고, 색인의 본문 목록과 실제 개념 파일 목록이 일치한다.
- 1단계 검색 8건에 2단계 검색 14건을 더해 총 22개 검색 경로를 확인했다.
  공핍층→P01, Vth→P02, CMOS→P03, FEOL→P04, 열산화→P05, ALD→P06,
  photoresist→P07, 선택비→P08, implant→P09, CMP→P10, via→P11,
  overlay→P12, EPM→P13, particle→P14. 이는 키워드 조회 점검이며 모델의 검색 품질 평가가 아니다.
- 2단계 계산 예제의 중간값·결과 23건을 대조했다: 바이어스 부호, VGS/VDS/overdrive,
  동적 전력·전압 제곱비, 두께 증가량/비율, GPC 두께·단차피복성, 노광량,
  선택비·식각 시간·마스크 손실, 주입 깊이 단위·평균 농도, CMP 제거율,
  배선 저항, CD 오차·overlay 벡터, 최초/최종 합격률, 입자 감소율.
  명시한 장채널 NMOS 모델의 동작 영역도 확인했다.
- 기존 1단계 계산 12건과 XOR 표를 함께 재확인했다. 1단계 본문은 수정하지 않았다.
- 공개 1차 자료를 읽고 출처별 사용 범위를 기록했다. 저항식, FEOL/MOL/BEOL 구분,
  CMP 관리 항목의 근거를 보강했다. 과거 제품 수치·전망을 현재 사실로 사용하지 않았다.
