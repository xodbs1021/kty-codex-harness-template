# 반도체 지식 패키지 검증 기록

확인일: 2026-10-30. 공개 기초 지식 패키지 검증이며 실제 Probe 접속·제공 Codex 실행 검증은 아니다.
최신 Sol+Sol 상태는 마지막 절과 [추가58개 원문 대조](reviews/2026-10-30-remaining-sources/README.md)를 따른다.
이전 [65개 본문 독립 검토](reviews/2026-10-30/README.md)도 이력으로 보존한다.
앞선 1–5단계의 독립 검수 미실행 표기는 각 단계 작성 당시 기록이다.

## 1단계 검증 범위

- Markdown 본문 11개, UTF-8 JSONL 색인 11개, 출처 레지스트리 14개.
- ID 유일성, 본문 경로 실존, source ID와 본문 URL 일치, 선수/관련 ID 실존, 선수 관계 비순환.
- Markdown 내부 파일 링크 확인.
- 검색 예시 8개에서 해당 개념 포함: 정전용량→F03, donor→F06, GiB→F07,
  MHz→F08, wafer→F09, NAND→F10, latency→F11, 에너지→F04.
- 본문의 직접 만든 계산 12건을 수치 계산으로 대조:
  3 mA, 0.5 mA, 20 fC, 6 J, 8 J, 10²² m⁻³, 2 GB,
  약1.863 GiB, 1 GB/s, 2 ns, 25%, 0.05 s. XOR 네 입력 조합 확인.
- 출처 14개는 공개 원 작성 기관의 페이지를 읽고 사용 범위를 기록했다.
  제품 현황으로 오해할 오래된 수치는 제외했다. 단위·공식 조건·가상 예제와 제품 수치 구분을 작성자가 검토했다.

구조·산술 검증은 기술 내용 전체의 정확성을 자동 증명하지 않는다.
독립 전문가 검수·실제 출제 적합성 평가·Sol+Sol 모델 검수는 이 지식 패키지에 아직 수행하지 않았다.
1단계 당시 확인 코드는 임시 점검이었다. 5단계에서 저장소에 재실행 가능한 `verify.py`를 추가했다.

## 재확인 방법

반입 저장소에서 `index.jsonl`의 관심 ID를 읽고 `path`로 본문을 연다.
`sources.json`의 출처 ID·확인 날짜와 본문 링크를 대조한다.
예제는 단위를 SI 기본값으로 맞춰 직접 계산하고, 실제 과제 수치로 바꿀 때는 조건을 먼저 확인한다.

현재 1–5단계 본문과 합성 예제를 제공한다. 실제 과제에서의 지식 선택·적용·실행 결과는 별도로 검증해야 한다.
재실행 명령과 범위는 [과제 적용 순서](application-playbook.md)를 따른다. 아래 각 단계의 개수는 해당 단계 완료 시점 기록이다.

이 검증은 자료 작성자의 출처 대조와 구조·산술 점검이다. 독립 전문가·Sol+Sol 검수나
실제 Probe 환경 검증을 수행했다는 뜻은 아니다. 별도 프로그램 설치 없이 파일을 읽어 사용한다.

- 기존 25개 본문과 해당 메타데이터·출처 35개가 이전 커밋과 같음을 확인했다.

## Sol + Sol 독립 전수 검토·수정 재검토 — 2026-10-30

기준 커밋731eecb의 동일 사본에서 `gpt-6.1-sol` 새 컨텍스트 두 개를 실행했다.
각각65개 본문과 적용 가이드·색인·출처 레지스트리·검증 코드를 읽었고 초기 결론을 서로 공유하지 않았다.
원문 관련 절 대조는 A21개·B15개, 합집합25개 출처다. 83개 전체 원문 재검증은 아니다.

- P2 한 건: F11의 전체 관측 처리량과 초기 대기 뒤 전송률에 같은 B를 쓴 혼용을
  B_obs/B_stream으로 분리했다. 100MB·2GB/s·대기0.01s의 총0.06s와 중복 가산0.07s를 검사에 추가했다.
- P3 세 건(중복 지적 통합): H07 방열판에서의 ΨJT 제한, D04 np0=2 희소 예제의 정확 이항
  꼬리확률0.004062와 정규3σ 차이, 계산91건이 고정 fixture이며 본문 숫자 전체 대조가 아니라는 설명을 보강했다.
- 두 Sol이 동일 동결 패치·변경7개 해시를 확인하고 영향 범위를 재검토했다.
  수용한 지적 모두 해소, 신규 지적 없음. 각 검토자가 수정본 검증기를 실행해 통과했다.
- 최종 구조65개/출처83개·키워드62건·기존 계산 fixture91건·합성 적용15개 검사 통과.
