# 데이터 단위·식별키·결합·결측

ID: `D01` · 단계 5 · 출처 확인: 2026-10-30

한 행이 무엇을 나타내는지 정한 뒤 결합과 결측 처리를 설계한다.

## 원리·적용 절차

lot/wafer/die/측정/검사 시도는 다른 단위다. 키·공정 단계·attempt·단위·시간대를 명시한다. 결합 전에 1:1 또는 m:1 조건을 확인하고 전후 행 수·고유 개체 수·미매칭을 기록한다. 결측은 미측정·적용 불가·수집 실패를 구분하고 0으로 자동 치환하지 않는다.

## 지표·공식과 적용 조건

결합 팽창률=결합 후 행 수/결합 전 행 수. 기대한 1:1/m:1 left join이라면 1이어야 한다. null 키는 별도로 점검한다. pandas에서는 null끼리 매칭될 수 있고 m:m 검증 옵션은 유일성을 검사하지 않는다.

## 직접 만든 적용 예제

가상 die 2개 중 A에 측정 3개, B에 1개가 있으면 그대로 결합한 결과는 4행이다. 행을 세면 다이 수가 2배로 보인다. 측정 단위를 유지하거나 목적에 맞춰 먼저 요약한다.

## 혼동·적용 한계

중복처럼 보이는 재검사를 무조건 삭제하지 않는다. 결측 대치 통계는 학습 구간에서만 정하며 전부 결측인 열의 처리도 기록한다. 정답 결측을 정상으로 만들지 않는다.
