# 이상 탐지·분포 변화·알람 운영

ID: `D11` · 단계 5 · 출처 확인: 2026-10-30

드문 관측·분포 변화·실제 불량은 서로 다른 판정이다.

## 원리·적용 절차

정상 기준만 학습해 새 관측을 탐지하는 경우와 오염된 학습 집합의 이상치를 찾는 경우를 구분한다. recipe 변경·센서 교체·누락 증가도 분포를 바꾼다. 기준·임계값을 고정하고 새 구간에서 평가한다.

## 지표·공식과 적용 조건

알람은 샘플 단위와 이벤트 단위로 따로 집계한다. 지속시간·병합 간격·정답 이벤트 매칭 창·지연을 먼저 정의한다. contamination 설정은 실제 불량률의 측정값이 아니다.

## 직접 만든 적용 예제

가상 연속10개 샘플의 알람을 한 이벤트로 묶었다면 샘플10건·이벤트1건이다. 사전에 “정상”으로 확인된1000구간에서 오알람20개면 관측 비율2%다. 정답이 없으면 오알람률을 계산했다고 하지 않는다.

## 혼동·적용 한계

이상 점수는 고장 확률·원인 증명이 아니다. 전체 시계열을 보고 기준을 다시 맞춘 결과를 실시간 검증으로 보고하지 않는다. 시간 상관을 고려한 검증 구간이 필요하다.

## 과제에서 확인할 질문

- 정상 기준·라벨 가용성·이벤트 단위가 정의됐는가?
- 분포 변화가 품종/센서 변화인지 실제 성능 저하인지 구분했는가?
