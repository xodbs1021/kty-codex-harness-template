# 2.5D·3D 패키징·인터포저·RDL

ID: `H03` · 단계 4 · 출처 확인: 2026-10-30

패키지 내부 수평 연결과 다이의 수직 적층은 함께 쓰일 수 있는 서로 다른 축이다.

## 원리·구조와 메커니즘

인터포저는 여러 다이 사이 고밀도 연결을 중계하고 RDL은 연결 위치를 재배치한다. 패키지 기판은 보드 연결까지 이어 준다. HBM 자체의 수직 적층을 로직과 나란히 배치하는 2.5D 통합과 구분한다.

## 지표·공식과 적용 조건

연결 경로를 로직 I/O→인터포저/RDL→HBM 단자로 추적하고 별도로 전원·접지 경로를 확인한다. 실리콘 전체 인터포저·국소 브리지·RDL 기반 구성을 모두 같은 구조로 간주하지 않는다.

## 직접 만든 적용 예제

가상 조립도에 로직 다이 1개와 HBM 스택 4개가 있어도 “총 5개 DRAM 다이”라고 집계하지 않는다. 스택 안 코어 수는 별도 BOM에서 확인한다.

## 혼동·적용 한계

CoWoS는 특정 공급자의 기술군 이름이다. 모든 2.5D 패키지가 같은 재료·구조·성능을 갖는 것은 아니다. 패키지 적층 층수와 NAND 셀 적층 층수를 혼동하지 않는다.

## 과제에서 확인할 질문

- 인터포저·기판·보드와 실제 측정 구간이 대응하는가?
