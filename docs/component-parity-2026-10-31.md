## 실제 기계 검사의 범위

`check_style.py --root <과제>`는 Git이 추적하거나 무시하지 않는 Go 파일을 검사한다.
모듈 파일이 없어도 검사하며 vendor·node_modules·가상환경과 무시된 파일은 제외한다.
파일을 고치지 않고 `gofmt -l`로 검사한다. 심볼릭 링크 대상은 따라가지 않고 미검증으로 보고한다.

- 종료 0: Go 포맷 통과 또는 적용 대상 없음. 출력 상태로 구분한다.
- 종료 1: 포맷 위반.
- 종료 2: 도구 부재·실행 실패·검사 불가.

verify는 스타일만으로 실제 과제 검사를 대체하지 않는다. checks가 비면 실패한다.
스타일 검사를 지운 checks 슬롯도 필수 스타일 단계를 없애지 못한다.
검사기 유실·실행 실패는 기존 성공 영수증을 무효화한다.
전체 읽기 전용에서는 반입본 검사기를 직접 실행하고 영수증을 쓰지 않는다.
이 검사는 Go 포맷만 자동 확인하며 모든 언어·명명·문서 규약을 판정하지 않는다.

원문 갱신기는 유지보수용이며 상류의 명시적 40자리 커밋만 받는다.
전부 내려받기 전 기존 사본을 변경하지 않는다. 시험 중 자동 갱신하지 않는다.
