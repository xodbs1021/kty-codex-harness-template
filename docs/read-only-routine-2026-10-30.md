# 설치 없는 루틴의 실제 읽기 전용 검증

2026-10-30, 로컬 macOS / Codex CLI 0.165.0에서 새 세션에
`하네스 설치해줘` 한 번만 전달했다. 메인과 두 독립 리뷰 세션 모두 실제
`read-only` 샌드박스였으며 승인 정책은 never였다. 권한 변경이나 사용자 추가 지시 없이
**129.241초(약 2분 9초)**에 가능한 루틴을 완료했다.

- 반입본 프로필·원칙·Skill·설치 없는 절차를 직접 읽었다.
- 합성 수율 계산 과제의 README·구현·테스트를 확인했다.
- `PYTHONDONTWRITEBYTECODE=1 python3 -B -m unittest discover -s tests -v`를
  실제 실행해 두 테스트 메서드가 통과했다. 테스트 코드도 읽어 쓰기 부작용을 확인했다.
- 새 컨텍스트의 리뷰 A·B를 실제 호출하여 두 응답을 받았다. 차단 지적은 없었다.
- 각 리뷰의 런타임 기록에서 `gpt-6.1-sol`, effort low, sandbox read-only를 확인했다.
  effort는 호출 인자로 강제하지 않았다. 메인은 실제 모델 텔레메트리가 없다고 보고했고,
  이 확인은 시험 제어기가 별도 런타임 기록으로 수행했다.
- 전후 파일 목록과 모든 과제 파일 SHA-256을 대조해 추가·변경이 없음을 확인했다.
- 최종 응답은 실제 검사·리뷰 결과와 설치·설정 저장·훅·영수증의 미완료를 구분했다.

이 결과는 **전체 설치 성공이나 자동 Stop 훅 활성화가 아니다.** 완료 대조는 에이전트가
지침을 따른 것이며 런타임의 강제 게이트가 아니다. 코드 수정·저장이나 쓰기가 필요한
빌드·테스트는 수행하지 않았다. 원래 쓰기 권한이 필요한 개발 작업까지 완료할 수는 없다.

제공 환경이 독립 에이전트를 지원해야 이 경로로 듀얼 리뷰를 수행할 수 있다.
Probe 지원 여부, 실제 과제의 테스트 부작용, 모델 가용성은 별도 확인 대상이다.
공개 저장소와 과제는 호출 전에 준비했으므로 탐색·clone·사용자 타이핑 시간은 포함하지 않았다.

검증 입력은 공개 커밋 `85fd7835c8cfca54b81649dfd4082b9014099d95`에 수정한
README·setup.md·read-only.md를 덮어놓은 사본이다. [기계 판독 기록](read-only-routine-2026-10-30.json)에
해당 세 문서의 정확한 SHA-256, 독립 세션 해시와 이벤트 파일 해시를 기록했다.
원시 로그는 개인 지침이 포함될 수 있어 공개하지 않는다. 배포 문서에는 이후 이 결과의 링크를 추가했다.
임시 신뢰 설정은 생성하지 않았고 테스트 CLI는 종료됐다. 기존 하네스 회귀 테스트 33개도 통과했다.
