# Probe 공개 실행 환경 확인 — 2026-10-28

공식 제품·문의 페이지, 공식 공개 데모와 그 페이지가 직접 불러오는 스크립트를 확인했다.
개인 응시 링크·접속 코드·사전체험 세션은 사용하지 않았고 문의 폼도 제출하지 않았다.

## 현재 확인한 접근 경로

| 경로 | 확인 결과 |
| --- | --- |
| [공식 Probe 제품 안내](https://www.getcofa.com/ko/probe) | 작업 환경·평가·감독 데모와 도입 문의로 연결 |
| [공개 작업 환경 데모](https://www.getcofa.com/brochure-v2/workspace-mock.html) | 미리 준비된 파일·터미널·메신저 화면을 표시하는 모의 UI |
| [데모 동작 스크립트](https://www.getcofa.com/brochure-v2/workspace-demo.js) | 파일·도구가 실제 명령을 실행하지 않는 로컬 상호작용 데모라고 명시 |
| [상호작용 스크립트](https://www.getcofa.com/brochure-v2/workspace-interaction.js) | 모의 terminal 등 화면 상호작용이며 제출·실행을 하지 않는다고 명시 |
| [도입 문의](https://www.getcofa.com/ko/contact) | 이름·회사·업무 이메일·문의 내용을 받는 도입 상담 경로 |
| [verify 하위 도메인의 공개 페이지](https://verify.getcofa.com/en/probe) | 확인한 경로도 같은 제품 소개와 모의 데모를 제공하며 실제 응시 세션이 아님 |

확인한 공식 공개 경로에서는 누구나 바로 쓸 수 있는 **실행형 터미널 샌드박스·개인용 체험판**을
찾지 못했다. 이는 공개 체험판이 전혀 존재하지 않는다는 증명이 아니라 이번 공개 확인의 한계다.
공개 데모에서 화면 구성을 익힐 수는 있지만 하네스 설치·실제 Codex·훅 검증은 할 수 없다.

현재 알려진 실제 응시 경로는 운영 측에서 주는 개인 접속 링크다. 아직 그 환경은 미접속이다.
별도 기술 점검용 샌드박스 제공 가능 여부는 운영 측 또는 Cofa에 확인해야 한다.
메시지 전송·신청·가입을 대신 진행하지 않았다. 공개되지 않은 경로나 타인 응시 세션을 찾지 않았다.
