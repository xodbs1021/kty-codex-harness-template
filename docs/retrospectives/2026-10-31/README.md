# 2026-10-31 통근버스 서비스 과제 기록

기록일: 2026-11-05. 사진 파일명의 날짜와 사용자의 설명으로 과제 시점을 연결했다.

- 사용자 설명: SK하이닉스 출퇴근 버스 노선을 짜고, 사용자와 관리자가 서비스를 사용하는 사이트를 만드는 과제였다.
- 사용자 설명: 서버 문제로 재시험 공지가 났다. 공지 원문·재시험 일시·문항 재사용 여부는 확인하지 않았다.
- 사진: 구현 뒤 제출 전 이해도 확인 2~5번 문항. 1번 사진은 없다.
- 제공되지 않은 자료: 전체 과제 명세, 데이터셋, 사용자가 작성한 코드, 실제 실행 결과, 최종 제출 답안.

## 원문과 출처

- [OCR 교정본과 보이는 화면 문구 전체](ocr.md)
- [가공하지 않은 Apple Vision OCR 결과](ocr-raw.json): 줄별 confidence와 이미지 정규화 좌표 포함.
- [구조화 기록·원본 이미지 SHA-256](records.json)
- [로컬 OCR 실행 소스](ocr.swift): ko-KR/en-US, accurate, 언어 자동 교정 비활성화.

이미지 바이너리는 이 기록에 포함하지 않았다. OCR 결과를 제공 이미지와 대조했다.
화면 밖·잘림·흐림은 복원하지 않았고 원문·교정·사용자 회상을 구분했다.
OCR confidence는 엔진 값일 뿐 전사 정확성이나 답변의 사실성을 보증하지 않는다.
