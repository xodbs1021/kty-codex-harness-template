## 별도 컨텍스트의 행동·이식 검토

- 한 Sol 하위 컨텍스트에 Skill과 합성 요구를 주고 명료화와 설계 설명을 수행하게 했다.
  이미 결정된 스택/출력은 묻지 않고 업무상 모호함을 드러냈으며,
  코드가 없는 상태의 제안을 구현된 구조로 설명하지 않았다.
  두 역할은 그 자식 안에서 순차 수행했으므로 역할 간 독립 호출을 증명하지 않는다.
- 다른 Sol 하위 컨텍스트가 원본 계약과 새 이식을 검토했다.
  계획만/검수만 요청의 종료 경로, 설계·계획 각 pass의 듀얼 검토,
  stdin 상속 문제를 지적해 수정했다. 재검토에서 해당 수정들을 확인했다.
  마지막 교차 검증 규칙의 참조 연결 지적도 workflow와 roles 문서에 반영했다.
- 위 자식들의 모델은 호출 시 Sol로 지정했으며, 실제 모델 확인은 CLI 실험의 런타임 헤더와 구분한다.
