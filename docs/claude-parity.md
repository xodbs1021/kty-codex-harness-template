접속 실패는 허위 인용과 구분해 보류하고, 공식 사양/웹 문서에는 발행 주체·버전·원문·적용 범위를
검토한다. 원본의 과제와 무관한 특정 서비스 예시나 운영 기록은 포함하지 않는다.

## 실제 실행과 제한

역할 파일은 `.codex/agents/`에 13개다. 전체 설치 시 설치기가 복사한다.
`harness.py role <이름> '<실제 요청>'`은 developer를 제외한 역할을 새 읽기 전용 Sol CLI로 실행한다.
기존 `review`·`audit` 별칭은 유지한다. 요청은 셸 문자열로 실행하지 않으며 비대화형 역할의 stdin은 닫는다.

자동 발견이 안 되면 TOML과 reference를 제공 독립 도구에 전달한다.
독립 도구가 없으면 같은 세션 대체 수행을 명시한다. 전체 읽기 전용이면 기록은 대화에 남긴다.
이 절차는 모든 역할의 자동 강제 실행을 보장하지 않는다. 파일 설치·역할 등록·실제 실행은 각각 확인한다.

구체적인 검증 결과는 [복원 검증 기록](role-restoration-validation.md)에 남긴다.
이전 15분/읽기 전용 리허설의 시간은 새 역할 전체 실행 시간으로 재사용하지 않는다.
